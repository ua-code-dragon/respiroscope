# parser and anova calculator

./data110 - root dir of source dataset

./subsets - root dir for filtered subset

./work/stat - root dir for filled subsets 

./work/imgs - plot images


## how to start

* create venv

* install dependncies 

* python toss.py to select proper subset from source to subsets

* python fill.py to flter subset, trim and fill missed fio2 

* python recalculate.py - to calculate ANOVA and create plots


./work/stat_anova.csv - ANOVA results

./work/imgs - plot files
